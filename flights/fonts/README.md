# Geist fonts

Unmodified variable WOFF2 fonts from Vercel's official `geist` npm package,
version **1.8.2** (`packages/next/package.json` in `vercel/geist-font`).

The npm registry was unavailable in this build environment, so these files were
retrieved from the official package's checked-in `dist` directory through the
GitHub connector, pinned to source tree
`b5d164a0c066c2c9bfcd5ab65dd8244551f0ac06`. The package's `prepare` script copies
the root `LICENSE.txt`; that same SIL Open Font License is included here.
